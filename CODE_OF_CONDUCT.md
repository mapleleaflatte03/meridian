# Code of Conduct

Meridian is a governance-focused open-source project. We expect:

- respectful, technical collaboration
- evidence-based discussion
- no harassment, intimidation, or abuse

## Scope

This policy applies to:

- GitHub issues, PRs, and discussions
- project chat spaces linked from this repository
- review and maintainer interactions

## Reporting

For conduct issues, open a private security/contact report through:

- https://github.com/mapleleaflatte03/meridian/security/policy

Maintainers may remove content or restrict participation for behavior that harms contributors or project integrity.
