## 2026-05-18 - Tooltips on disabled buttons require pointer-events: none
**Learning:** When trying to add a tooltip (`title` attribute) explaining a disabled state, applying it directly to the `<button disabled>` element fails because disabled HTML elements typically don't fire mouse events (including hover). To fix this, you have to wrap the button in a container element (like a `span`), add the `title` and `cursor: not-allowed` to the wrapper, and crucially, apply `pointer-events: none` to the disabled button itself so the wrapper can properly receive the pointer events.
**Action:** Whenever adding tooltips to disabled elements in this app's components, I will use this wrapper pattern and dynamically restore `pointer-events: auto` and clear the `title`/`cursor` properties when the element is re-enabled to prevent unexpected lingering behavior.
