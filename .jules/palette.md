## 2026-05-18 - Tooltips on disabled buttons require wrapper elements
**Learning:** Native `title` attributes on `disabled` elements do not work because they don't capture pointer events. Furthermore, when adding wrapper elements for tooltips on buttons that dynamically change between disabled and enabled states, you must dynamically manage the `tabindex` of the wrapper element to avoid an accessibility regression where keyboard users experience confusing double tab stops (one for the wrapper, one for the button) when the button is enabled.
**Action:** When adding tooltips to disabled buttons, use a wrapper element (like a `<span>`) with the `title` attribute. If the button state is dynamic, use JavaScript to set `tabindex="0"` on the wrapper when the button is disabled, and remove the `tabindex` when the button is enabled to ensure a single, logical focus stop. Use inline styles sparingly, but `style="display: inline-block;"` is necessary on spans for tooltips to render correctly without custom CSS classes. Never use `style="pointer-events: none;"` on the button itself if its disabled state is dynamically managed.
