## 2026-05-18 - Explaining disabled states with aria-describedby
**Learning:** When trying to explain *why* an element is disabled (like telling a user "Select items first" on a disabled bulk action button), adding an `aria-label` is dangerous because it completely replaces the accessible name of the button (e.g., "Approve" becomes just "Select items first"). Using a hidden description element (`<span id="..." class="operator-hidden-field" aria-hidden="true">...</span>`) and pointing to it via `aria-describedby` on the disabled button safely provides the context to screen readers without destroying the button's identity.
**Action:** Use `aria-describedby` pointing to a visually hidden description to explain disabled states to assistive technologies instead of using `aria-label` or complex wrapper hacks that break layout and keyboard accessibility.
