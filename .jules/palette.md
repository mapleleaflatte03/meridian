## 2024-05-06 - Tooltips for disabled buttons
**Learning:** When adding tooltips to disabled elements, it's safer and easier to use the native `title` attribute rather than adding custom CSS or JS-driven tooltips, especially when restricted to existing classes. This is an accessible way to explain *why* a button is disabled.
**Action:** Use the `title` attribute for disabled element tooltips when native HTML is preferred or custom CSS is restricted.
