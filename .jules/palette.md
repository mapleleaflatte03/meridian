## 2024-05-24 - Tooltip for disabled buttons
**Learning:** Found multiple disabled buttons in `trust-ops.html` for bulk actions (approve, stale, revoke, unresolved) that provide no explanation to users on why they are disabled or how to enable them. Since users notice the little things, explaining how to unlock these actions by selecting items improves accessibility and clarity. Because disabled buttons do not fire hover events on some browsers, wrapping them in an element that handles the `title` attribute for tooltip on hover is an established best practice. Wait, there's a constraint: "Use existing classes (don't add custom CSS)". Thus we must use inline styles to apply `cursor: not-allowed` and `display: inline-block` on the wrapper span, and `pointer-events: none` on the button.
**Action:** Always wrap disabled buttons in spans with `cursor: not-allowed` and apply `pointer-events: none` to the button to ensure tooltips appear on WebKit browsers. If custom CSS is banned, use inline styles for these specific properties.
