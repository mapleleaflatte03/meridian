## 2024-05-13 - [Tooltip for Disabled Button Workaround]
**Learning:** Native `title` attributes do not display on `disabled` HTML elements (e.g., `<button disabled>`) because they do not capture pointer events in most major browsers. Do not attempt to use `title` directly on disabled elements to provide tooltips without workarounds like wrapper elements. When using wrapper elements to provide tooltips for disabled buttons, do not hardcode `tabindex="0"` if the button's disabled state is dynamically toggled by JavaScript. The `tabindex` must be dynamically removed when the button is enabled to prevent an accessibility regression where keyboard users encounter confusing double tab stops.
**Action:** When dynamically adding a tooltip wrapper (like a `span` with a `title` attribute) around a button to explain its disabled state, you must ensure your JavaScript also dynamically removes or updates the `title` attribute when the button becomes enabled. Failing to do so causes the 'disabled' tooltip to incorrectly persist on the active element. When adding tooltip wrappers to disabled buttons (to work around native `title` attribute limitations), do not apply inline styles like `style="pointer-events: none;"` to the button if its disabled state is dynamically managed by JavaScript. This permanently breaks interactivity because the inline style persists even after the `disabled` attribute is removed.
