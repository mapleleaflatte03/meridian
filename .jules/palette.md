## 2026-04-18 - Dynamically Managed Tooltips on Disabled Elements
**Learning:** Native `title` attributes do not display on disabled HTML elements because they do not capture pointer events. While using a wrapper element with `tabindex="0"` works around this for static disabled elements, if the element's disabled state is managed dynamically by JS (like the bulk action buttons in Trust Ops), both the `title` and `tabindex` on the wrapper MUST be dynamically removed when the button is enabled. Otherwise, keyboard users experience a confusing double tab stop (wrapper + enabled button) and mouse users see a 'disabled' explanation on an active button.
**Action:** When adding tooltip wrappers for dynamically disabled elements, always update the JS to toggle `title` and `tabindex` properties on the wrapper concurrently with the button's disabled state.
