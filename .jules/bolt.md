## 2024-06-23 - Fast deepcopy in Python
**Learning:** `copy.deepcopy` in python is surprisingly slow because it handles circular references, arbitrary objects, class state, and memoization. We can get a 3-4x speedup by writing a custom recursive copy that just copies dicts, lists, and tuples if we know the payload is just a simple JSON-like structure (which many caching objects in our code are, e.g., in status_surface).
**Action:** Replace `copy.deepcopy` with a simple type-checking recursive dict copy or `json.loads(json.dumps())` when dealing with pure JSON-like dict caches. However, be careful not to use JSON dumps on objects with un-serializable primitives (like `datetime.datetime` or `uuid.UUID`) to avoid crashes. A type-checking dict copy is safer as it copies primitives by reference (which are immutable).
