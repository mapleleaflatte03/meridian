## 2024-05-29 - Optimize dictionary value iteration in loops
**Learning:** In Python, iterating over values extracted from a dictionary with `list(dict.get('key') or [])` creates an unnecessary O(n) shallow copy of the list. This negatively impacts performance on large datasets. Due to Python's operator precedence, it is also important to wrap the expression in parentheses if slicing is involved (e.g. `(dict.get('key') or [])[:20]`) to avoid functional regressions where slicing would only apply to the fallback empty list.
**Action:** When extracting arrays/lists from dictionaries for iteration where mutation of the list itself is not required, use `(dict.get('key') or [])` instead of `list(dict.get('key') or [])`. Avoid using this pattern on `dict.items()`, `dict.values()`, or `dict.keys()` if the loop modifies the dictionary structure.
