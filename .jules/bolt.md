## 2024-05-26 - Avoid unnecessary O(n) shallow copies when iterating dictionary values or lists
**Learning:** Python's `list(data.get('key') or [])` executes an O(n) shallow copy, which can be expensive and cause performance degradation when the copy isn't required (e.g. read-only traversal or loops that don't modify the source lists/dictionaries or simply using lists obtained via `.get()` that are already fresh instances). When iterating dictionary values or fallback empty lists, using `for item in (data.get('key') or []):` avoids wrapping the result in `list()` and gives a 40-50% improvement for iteration loops.
**Action:** Do not wrap read-only dictionary value access or slice defaults in `list()` within `for` loops unless specifically modifying the structure during iteration (like `dict.values()`). Apply `(data.get('key') or [])` directly.
