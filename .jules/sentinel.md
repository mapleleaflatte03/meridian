## 2024-11-04 - Path Traversal Vulnerability in WebAPIAdapter
**Vulnerability:** A path traversal vulnerability was discovered in `intelligence/meridian_gateway.py` where static assets are served. User input from the URL (`request_path.removeprefix('/assets/')`) was joined with a base directory (`COMPANY_DIR / 'www' / 'assets'`) and resolved. The security check used `str(asset_path).startswith(str(assets_root))`.
**Learning:** String `startswith` matching on file paths is insecure for preventing directory traversal. If `assets_root` is `/app/www`, an attacker could request `/assets/../www-secret/file.txt`, which resolves to `/app/www-secret/file.txt`. The string `"/app/www-secret/file.txt"` still starts with `"/app/www"`, bypassing the check and allowing access to files outside the intended directory.
**Prevention:** Always use `pathlib.Path.is_relative_to(target_directory)` instead of string prefix matching when validating directory boundaries in Python. This ensures path structure is correctly evaluated rather than relying on naive string comparisons.
