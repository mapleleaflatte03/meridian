## 2024-08-14 - Prevent SQL Injection via Environment Variable in PRAGMA statement
**Vulnerability:** The SQLite PRAGMA journal_mode statement in `observability_store.py` dynamically interpolated the environment variable `MERIDIAN_OBSERVABILITY_SQLITE_JOURNAL_MODE` directly into an executable query (`conn.execute(f'PRAGMA journal_mode={configured_journal_mode}')`). This allowed command injection, where a malformed environment variable like `"WAL"; CREATE TABLE hacked (id INT);` could execute arbitrary SQL statements.
**Learning:** Python's SQLite3 library does not support parameterized inputs (`?`) for `PRAGMA` statements. Consequently, input sourced from unvalidated channels (like environment variables) cannot be safely parameterized directly.
**Prevention:** For `PRAGMA` and other non-parameterizable statements, externally sourced input must always be validated against a strict allowlist of permitted values (e.g., `{'DELETE', 'TRUNCATE', 'PERSIST', 'MEMORY', 'WAL', 'OFF', 'DEFAULT', ''}`) prior to string interpolation.
