## 2024-05-15 - Unsafe PRAGMA journal_mode configuration injection

**Vulnerability:** SQL injection vulnerability in `observability_store.py` when executing `PRAGMA journal_mode={configured_journal_mode}` because `configured_journal_mode` is taken directly from the `MERIDIAN_OBSERVABILITY_SQLITE_JOURNAL_MODE` environment variable and wasn't validated against an explicit allowlist. Since SQLite's `PRAGMA` statement doesn't support parameterized queries (e.g., `?`), direct interpolation allows for SQL injection if the environment variable can be influenced by a malicious actor.
**Learning:** In Python's `sqlite3` module, `PRAGMA` statements do not support parameterized queries (e.g., `?`). When dynamically generating `PRAGMA` queries using externally controlled configuration (such as environment variables), you must strictly validate the input against an explicit allowlist of acceptable values before execution to prevent SQL injection vulnerabilities.
**Prevention:** Validate values coming from environment variables, particularly those used in `sqlite3.Connection.execute()`, especially `PRAGMA` commands, using strict allowlists (e.g. `{'DELETE', 'TRUNCATE', 'PERSIST', 'MEMORY', 'WAL', 'OFF'}`).
