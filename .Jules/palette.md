## 2026-05-22 - Disabled Button Tooltips Suppression
**Learning:** Native `title` attributes on `<button disabled>` elements do not render tooltips in modern browsers because pointer events are suppressed on disabled elements. Additionally, adding CSS like `pointer-events: none` directly to disabled elements prevents custom hover states or tooltips entirely.
**Action:** Always wrap disabled buttons in another element (like a `<span>` or `<div>`) to hold the tooltip/`title` if it needs to be visible while disabled, OR apply `pointer-events: auto` to the disabled button in CSS (which overrides default behavior but might cause form submission issues if not careful). If a tooltip explaining *why* a button is disabled is required, wrap the button. Here we are just adding titles to buttons so they are available when enabled, but adding disabled styles to clarify their state when disabled.
