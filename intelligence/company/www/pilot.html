Get started with Loom

Install Loom and run your first agent in minutes.

One command installs the full Meridian stack: Loom runtime, Kernel governance, and workspace services. Then create a governed agent and watch it run.

Scope
What this gives you Loom + Kernel + workspace on your machine.
What this is not No purchase flow. No gated usage. Fully open source.

1. Clone the monorepo

git clone https://github.com/mapleleaflatte03/meridian.git
cd meridian

2. Bootstrap full stack

curl -fsSL https://raw.githubusercontent.com/mapleleaflatte03/meridian/main/scripts/install-full.sh | bash

This command clones or reuses the monorepo, initializes Kernel state, and builds the Loom CLI in release mode.

3. Run first-time onboarding

./scripts/onboard.sh

Guided flow that creates your institution, first agent, and local workspace config. Everything stays on your machine. No data is uploaded anywhere.

  • Sets: institution name, plan, first agent name and role
  • Demo data import: opt-in only (default: no)
  • Governance gates: on by default
  • Non-interactive: MERIDIAN_INST_NAME="My Org" MERIDIAN_AGENT_NAME="Assistant" ./scripts/onboard.sh --non-interactive

4. Bring up local stack (workspace + gateway)

./scripts/dev-up.sh

Run this after onboarding to start workspace services.

  • Local API status: http://127.0.0.1:8266/api/status
  • Local institution template: http://127.0.0.1:8266/api/institution/template
  • Local treasury snapshot: http://127.0.0.1:8266/api/treasury
  • Open /proofs for runtime proof posture.
  • Open /workflows for live workflow showcase.
  • Open /boundary for current claim boundary.

5. Create and run your first agent (alternative)

cd ~/meridian
./scripts/new-first-agent.sh "My Assistant"

# Optional: run immediately
MERIDIAN_RUN_AGENT_NOW=1 ./scripts/new-first-agent.sh "My Assistant"

Use the helper for the shortest path. It initializes Kernel state, provisions the agent, and prints the exact run command.

Shortcut alternative to onboard.sh for users who want to skip the guided setup and provision an agent directly.
