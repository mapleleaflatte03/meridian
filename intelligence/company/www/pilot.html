Get started with Meridian Core

Install Meridian Core and start running agents in minutes.

One command installs the full stack. Then run onboarding with --mode core for quick setup, or the interactive flow for full Team configuration. Core gives you browser tasks, research, memory, and scheduling without governance deep-dive.

Scope
What this gives you Meridian Core, Team, and the local stack on your machine.
What this is not No purchase flow. No gated usage. Fully open source.

1. Clone the monorepo

git clone https://github.com/mapleleaflatte03/meridian.git
cd meridian

2. Bootstrap full stack

curl -fsSL https://raw.githubusercontent.com/mapleleaflatte03/meridian/main/scripts/install-full.sh | bash

This command clones or reuses the monorepo, initializes the local runtime stack, and builds the CLI tooling in release mode. It does not create your institution; onboarding does that in the next step.

3. Run first-time onboarding

Core mode (recommended for most users):

./scripts/onboard.sh --mode core

Quick setup with sensible defaults. No governance choices required. Creates your institution and first agent, then shows you how to run daily tasks with ./scripts/core.sh.

Interactive mode (full Team configuration):

./scripts/onboard.sh

Guided flow with full configuration choices for plan, governance, and execution route.

  • Non-interactive: MERIDIAN_INST_NAME="My Org" MERIDIAN_AGENT_NAME="Assistant" ./scripts/onboard.sh --non-interactive
  • Everything stays on your machine. No data is uploaded anywhere.

4. Run daily tasks with Core

After Core onboarding, run tasks immediately:

./scripts/core.sh browse https://example.com
./scripts/core.sh research "echo hello"
./scripts/core.sh remember my_note "something to save"
./scripts/core.sh recall my_note
./scripts/core.sh schedule daily_check 86400
./scripts/core.sh inspect

Or explore the public proof surfaces: /proofs · /workflows · /demo
