Install Meridian (Loom-powered runtime)

This is the one install command for Meridian. Loom powers runtime execution after onboarding mode selection.

One-command full-stack install

curl -fsSL https://raw.githubusercontent.com/mapleleaflatte03/meridian/main/scripts/install-full.sh | bash

This installs Meridian locally (runtime + governance + interfaces) and builds the Loom CLI at $HOME/meridian/loom/target/release/loom.

Canonical first-run path

01

Run onboarding

Use ./scripts/onboard.sh to create your local institution and first governed agent.

02

Start local stack

Run ./scripts/dev-up.sh to start your local workspace and gateway services.

03

Inspect local proof

Open your local proof and status routes at http://127.0.0.1:8266.

04

Operate agent loops

Use loom run-agent, loom status, and memory tools after onboarding completes.

cd ~/meridian
./scripts/onboard.sh

# non-interactive option
MERIDIAN_INST_NAME="My Org" MERIDIAN_AGENT_NAME="My Assistant" ./scripts/onboard.sh --non-interactive

Guided onboarding is the canonical first-run path. It creates your local institution and first governed agent before you start local services.
