# Safe Web Research

This skill enables safe web research and browsing capabilities for extracting information from public URLs. It provides controlled web fetching with proper error handling and content extraction.

## Capabilities

- Extract and fetch content from public URLs
- Parse and summarize web content
- Handle various content types (HTML, text, etc.)
- Provide structured extraction from web sources

## Usage

Use this skill when you need to:
- Extract specific information from a website
- Browse and summarize web content
- Verify facts from online sources
- Get current data from public web pages

## Constraints

- Only works with public URLs
- Does not execute JavaScript or handle dynamic content
- Provides text-based content extraction
- Maintains safe browsing practices
