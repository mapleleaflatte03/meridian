# Sustainability Policy (Non-Coercive)

Meridian is open source first. Sustainability channels are optional and must not gate core usage.

## Principles

1. No paywall for install, runtime, governance surfaces, or contribution.
2. Optional support must be clearly labeled as optional.
3. Research and infrastructure funding should not alter truth boundaries in public claims.

## Support Channels

- GitHub Sponsors: https://github.com/sponsors/mapleleaflatte03
- Patreon: https://www.patreon.com/
- Consulting/research collaboration: maintainer contact paths
- Grant applications for open governance/verification research

## Out of Scope

- Mandatory commercial checkout in onboarding
- Feature gating by payment tier for core runtime/governance paths
- Closed governance modules sold separately from OSS core
