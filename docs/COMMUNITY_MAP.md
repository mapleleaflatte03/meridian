# Meridian Community Map

## Canonical Channels (Current)

- GitHub Issues: https://github.com/mapleleaflatte03/meridian/issues
- GitHub Discussions: https://github.com/mapleleaflatte03/meridian/discussions
- GitHub Sponsors: https://github.com/sponsors/mapleleaflatte03
- Telegram (maintainer contact): https://t.me/Enhanhsj
- Discord: not yet public as canonical support channel (GitHub-first while moderation automation is hardened)

## Channel Intent

- Issues: bugs, regressions, feature work.
- Discussions: architecture, roadmap, research RFC drafts.
- Telegram: maintainer contact and escalation only.
- Sponsors: optional sustainability support.

## Contribution Routing (No Ambiguity)

1. Runtime or governance bug -> open Issue
2. Architecture or research proposal -> open Discussion
3. Ready implementation -> open PR linked to issue/discussion
4. Security-sensitive report -> private disclosure path (security policy)

## SLA Baseline

- Initial issue triage target: 72h.
- Reproducible bug with logs/tests: prioritized over vague reports.
- Research RFC reviews: asynchronous in discussions, then implementation issue.

## Moderation Policy

- Governance-impacting claims must include evidence.
- Security-sensitive details must use private disclosure flow.
- Archived mirrors are non-canonical and read-only.
